## A. 小功能：trace 增加正整数 --limit

当前产品 trace 支持 workspace/run/layer/direction/follow/raw；请先用 `mokioclaw trace --help` 确认接口。此题还未实现，不要把评测副本的 `--since` 实现移植过来当答案。

要求：

1. `mokioclaw trace --limit N` 最多输出 N 条**经过现有过滤后**的记录；默认不设上限，兼容原行为。
2. N 必须为正整数；0、负数及非整数由 CLI 返回参数错误，且不读取 trace。
3. raw 与普通展示均按记录计数；不按文本换行计数。
4. follow 达到上限后退出；没有匹配记录时继续等待，不能按读取的原始条数提前结束。
5. 只读，不创建 daemon、调用模型或重放工具；不改变已有事件和评分口径。

验收：至少覆盖默认兼容、过滤后计数、raw、非法输入、follow 到达上限；在临时目录构造小型 JSONL，不依赖已有 HOME 或网络。说明每项测试能防止的错误，不能只复制实现逻辑。

交付练习补丁、测试结果及为何选择该模块；本 Goal 只出题，不替本人完成此功能。
