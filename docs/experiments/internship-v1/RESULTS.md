## 配置核对和事件缺陷

底层 canonical trace 的 1,903 次请求与运行计数逐项一致；全部使用同一模型、32768/4096 预算和 SDK 零自动重试。
模型设置、调度和可信评分具备本评测集内的对照条件。初始外层事件严格核对失败，没有删除这份失败结果。
