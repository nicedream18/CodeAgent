# Third-party evaluation material

The four public task rows and patches are from Princeton NLP SWE-bench Lite,
revision 6ec7bb89b9342f664a54a6e0a6ea6501d3437cc2:
https://huggingface.co/datasets/princeton-nlp/SWE-bench_Lite/tree/6ec7bb89b9342f664a54a6e0a6ea6501d3437cc2

Upstream repositories: https://github.com/pallets/flask and https://github.com/psf/requests.
Their exact base commits, archive and patch hashes are recorded in external.json and task manifests.
Copies of each base revision's LICENSE are in licenses/E01-LICENSE through E04-LICENSE.
These retain their upstream terms; inclusion does not change the MokioAgent project's licensing.
This custom offline subset is not an official SWE-bench benchmark result.

baseline.tar.gz is an archive of the user's MokioAgent repository at 6e88c21,
used only to prepare reproducible first-party task snapshots without later Git history.
